# مؤسسة العقيلة الثقافية الخيرية

موقع عربي باتجاه RTL (من اليمين إلى اليسار) مبني باستخدام Next.js وReact وTailwind CSS.

## أقسام الموقع
- الصفحة الرئيسية: التعريف ورسالة المؤسسة وآخر الأخبار.
- عن المؤسسة.
- الأخبار: المحتوى المنشور.
- المشاريع والمبادرات.
- المحاضرات.
- المكتبة: روابط وملفات.
- اتصل بنا.
- لوحة الإدارة: `/admin/login` و `/admin`.

## لوحة الإدارة
تستخدم Supabase للمصادقة والبيانات وتخزين الملفات. إدارة الموقع مقيدة بأعضاء جدول `admin_users`.

## إعداد الموقع
اقرأ ملف [SUPABASE_SETUP.md](./SUPABASE_SETUP.md) للحصول على تعليمات الإعداد باللغة العربية، وراجع [sql/schema.sql](./sql/schema.sql) لإعداد الجداول والصلاحيات والتخزين.

متغيرات البيئة المطلوبة:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

## التشغيل محلياً
1. تثبيت Node.js (18 أو أحدث).
2. تنفيذ `npm install`.
3. إعداد ملف `.env.local` بالمتغيرات المذكورة أعلاه.
4. تنفيذ `npm run dev`.
5. فتح `http://localhost:3000`.

## البناء والنشر
`npm run build`

المشروع مهيأ للتصدير الثابت مبدئياً. لم يتم اختبار البناء أو نشر الموقع حتى الآن. يلزم التحقق من توافق منصة النشر وتكوين متغيرات البيئة.
