# مؤسسة العقيلة الثقافية الخيرية

موقع عربي (RTL) باستخدام Next.js وReact وTailwind CSS.

## الأقسام الحالية
- الرئيسية
- عن المؤسسة
- المشاريع
- المحاضرات
- المكتبة
- اتصل بنا

## التشغيل محلياً
1. تثبيت Node.js (الإصدار 18 أو أحدث).
2. تنفيذ: npm install
3. تنفيذ: npm run dev
4. فتح http://localhost:3000

## البناء
npm run build

المشروع مهيأ مبدئياً للتصدير الثابت عبر Next.js. لم يتم ربط قاعدة البيانات أو لوحة الإدارة بعد.
